# Patient Readmission Analysis

## Objective
Analyze patient and hospital-related factors associated with hospital readmission.

## Dataset
The dataset contains patient demographic, hospital, treatment, and readmission information.

## Analysis
- Data Loading and Inspection
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Statistical Analysis

## Statistical Methods
- Mann-Whitney U Test
- Chi-Square Test

## Key Findings
Age, previous visits, length of stay, diagnosis, and admission type showed statistically significant associations with readmission at the 5% significance level.
